## Contenido

El proyecto está organizado en **5 lecciones**:

### Lección 1 Script sencillo que lee datos de entrda y muestra al usuario la salida
- Utilización `prompt()` para solicitar datos de entrada.
- Uso de `alert()` para mostrar mensajes al usuario.

### Lección 2 Calculadora simple con las cuatro operaciones matemáticas básicas.
- Uso de estructuras condicionales `if`, `else` y `switch`.
- Declaración y uso de variables `let` y `const`.

### Lección 3 Creación y manipulación de arreglos.
- Recorrido de elementos mediante ciclos `for` y `while`.
- Implementación de una función para filtrar elementos según una condición.

### Lección 4 Implementación de una calculadora básica con funciones.
- Creación de una función que recibe parámetros y retorna un resultado.

### Lección 5 Conceptos básicos de objetos.
- Creación de objetos con propiedades y valores.
- Implementación de métodos dentro de un objeto.
- Uso de arreglos de objetos.
- Recorrido de colecciones mediante `forEach()`.

## Notas

En todas las lecciones se utiliza `console.log()` para mostrar información y resultados durante la ejecución del programa.
