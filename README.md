Proyecto Fundamentos de programacion JS curso Front End.
En este proyecto encontraras 5 Lecciones de Programación Javascript:
Lección 1.- Un script sencillo que utilize prompt() para solicitar datos de entrada y mensajes con alert()
Lección 2.- Calculadora simple con las 4 operaciones matemáticas basicas, utilizando estructuras codicionales if,else,switch con utilización de variables let y const
Lección 3.- Creación de arreglos con elementos, utilizacion de ciclos for y while para su reccorido, implementacion de una función para el filtrado según condición.
Leccion 4.- Implementación de una calculadora básica, con una función que reciba parámetros y retorne el resultado
Lección 5.- Creación de un objeto con propiedades y valores, implementación de métodos dentro del objeto, uso de arreglo de objetos y recorrido con forEach().
En todas estas lecciones se utiliza console.log() para mostrar mensajes al usuario.
